# External references and optional tools

The bundled diagrams and their generating code are original illustrative material released under this repository's MIT license. No external paper images, logos, fonts, or converter implementation are included.

## Optional conversion engine

[FigGenie-paper-diagram-skill](https://github.com/Sleepy-Avacado/FigGenie-paper-diagram-skill) supplies the optional SVG-to-PowerPoint engine. The adapter in this repository imports a user-selected installation. Install that project separately and follow its license and dependency instructions.

Python libraries used by optional scripts include CairoSVG, python-pptx and lxml. They are installed separately and retain their own licenses.
